📝 To-Do List App (Python)

📌 Description

This is a simple To-Do List application built using Python. It allows users to manage their daily tasks efficiently through a command-line interface. The application supports adding, viewing, and deleting tasks, and stores data in a file so tasks are saved even after the program is closed.



🚀 Features

* Add new tasks
* View all tasks
* Delete tasks
* Data stored permanently using a text file



🛠️ Technologies Used

* Python
* File Handling


▶️ How to Run

1. Install Python on your system
2. Download or clone this repository
3. Open terminal or command prompt
4. Run the program using:

   python todo.py
  

💡 Future Improvements

* Add task completion status
* Add deadlines and priorities
* Create a GUI using Tkinter
* Convert into a web application


🙌 Conclusion

This project is a beginner-friendly application that helps in understanding basic Python concepts like loops, functions, and file handling. It is a great starting point for building more advanced projects.
